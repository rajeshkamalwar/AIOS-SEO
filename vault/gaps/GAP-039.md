# Raw retention privacy scope

Existing `acceptHttpFixture` retains exact supplied HTML with `none-v1`; synthetic-only scope is enforced. The rendered-artifact transformation in [GAP-038](GAP-038.md) does not fix or certify this upstream raw retention path. Any repair must preserve explicit source/preparation lineage and coverage; silently rendering a scrubbed inert projection as though it were the original page would distort evidence.
