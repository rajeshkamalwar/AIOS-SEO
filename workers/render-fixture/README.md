# Offline synthetic renderer

This one-shot Linux worker replays a supplied `.example` HTML fixture with real pinned Chromium. It is an N1 isolation and DOM-sampling test target, not an authorized live renderer or crawler. It accepts only `{url, html}` on stdin and returns one bounded JSON receipt; it has no database, storage or model credentials and persists nothing.

Run `npm run test:render` from the repository root with Docker available. `AIOS_DOCKER_CONTEXT` optionally selects a Docker context; no other isolation flags are configurable. The harness builds the digest-pinned image and always kills/removes each named container, including on host timeouts. It does not mount the host or Docker socket. Use a dedicated local VM without home/agent forwarding for development.

The fixed runtime denies networking at the container layer, uses nonroot Chromium with its namespace and seccomp sandboxes enabled, drops all capabilities, denies privilege escalation, makes the root filesystem read-only, and bounds memory, CPU, PIDs, shared memory and temporary storage. The worker verifies Linux identity, effective capabilities, seccomp and offline interfaces, then probes Chromium's sandbox status before handling the fixture. These are regression probes, not a claim of proven resistance to all browser/kernel escapes.

Only the initial main-document request is fulfilled from the supplied fixture. All additional resource requests, POSTs, sockets, popups and downloads are denied. Service workers are disabled. The initial navigation plus 99 denied attempts terminates rendering. DOM samples at DOMContentLoaded and +2/+5 seconds retain actual timing; changed URL context cannot produce a sample under the original URL. Oversize DOM, blocked resources and budget exhaustion remain policy limitations. Failure before DOM returns no samples. The terminal receipt ends the process, and host supervision independently kills hung containers.

Raw observed HTTP status/body/evidence must remain separate from this synthetic replay. The replay's fulfilled 200 status is transport plumbing, not a site observation. Output is not yet accepted into the governed evidence ledger, and this worker grants no render job, resource egress, customer-data or production deployment authority.

`seccomp.json` is vendored from [Playwright v1.63.0](https://github.com/microsoft/playwright/blob/v1.63.0/utils/docker/seccomp_profile.json), under the accompanying Apache-2.0 license. It adds an unconditional `chroot` syscall allowance because dropping all outer capabilities removes the upstream conditional permission required by Chromium's own user-namespace sandbox. No outer capability is restored. [Playwright Docker guidance](https://playwright.dev/docs/docker) explicitly treats its image as development/testing infrastructure. The image is pinned by version and manifest digest; browser build is reported from the running binary. This local image is not a production-image recommendation.

The host conformance harness validates original stdout bytes with `parseOfflineRenderResult`, using a browser version read separately from the installed image metadata. Invalid UTF-8, malformed/state-inconsistent receipts and DOM strings that cannot roundtrip to UTF-8 are rejected. Valid samples are also checked through bounded inert extraction with original-byte locators. These checks establish shape and local conformance, not authentic worker attestation or permission to accept evidence.

The current receipt profile is `local-offline-replay-v2`. It includes `inputSha256`, computed from the exact validated UTF-8 HTML bytes fulfilled to Chromium. The host independently supplies that digest to validation; v1/unbound/mismatched receipts are rejected. Invalid UTF-8 and lone-surrogate input fail before admission with null URL/digest and no samples. This binds fixture content for conformance; it is not proof of worker authenticity or production authorization.

`prepareOfflineRenderInput` prepares caller-authorized retained fixture HTML using its full response Content-Type. It retains the source evidence ID/raw digest separately from decoded UTF-8 replay bytes, input digest, encoding and transformation version. Unsupported, truncated, undecodable or oversized input abstains. The conformance suite exercises a declared legacy charset through real Chromium. Host timeout errors include operation and deadline; neither this preparation nor the test harness grants live renderer authority.
