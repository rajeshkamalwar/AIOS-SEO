# Parallel Brain Architecture

## Functional layers
1. **Perception:** website, raw/rendered HTML, search platforms, SERPs, market, competitors, authority, local, analytics and AI-search sensors.
2. **Truth Layer:** provenance, freshness, confidence and source class for every important claim.
3. **Digital Business Twin:** business, offerings, customers, geography, constraints and conversion model.
4. **Search Knowledge Graph:** connects business → offering → customer → location → intent → demand → query → page → SERP → competitor → authority → action → result.
5. **Opportunity Engine:** determines where the business can realistically win next.
6. **Strategy Brain:** converts opportunities into coherent multi-step plans.
7. **Skills Runtime:** loads current domain procedures and platform constraints.
8. **Agent Runtime:** specialized bounded workers use explicit tools.
9. **Policy/Risk Guardian:** evidence, confidence, reversibility, blast radius and policy.
10. **Action Engine:** preview, approval/auto, deployment, verification and rollback.
11. **Evaluation:** frozen success criteria and observation windows.
12. **Temporal Memory:** what happened, what was believed, what changed and what followed.
13. **Learning:** site-specific strategy confidence and reusable priors.
14. **Self-Audit:** whether the Brain itself is trustworthy enough to act.

Heartbeat: `Sense → Update world model → Detect change → Decide if it matters → Investigate → Prioritize → Plan → Validate → Act → Observe → Learn`.
