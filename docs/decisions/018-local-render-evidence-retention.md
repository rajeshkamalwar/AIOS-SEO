# ADR-018: local render evidence retention and acceptance

Status: Accepted reversible local engineering default.
Date: 2026-09-18.

[ADR-017](017-governed-local-render-execution.md) establishes physical execution and accounting, not artifact acceptance. [26](../26-TEMPORAL-EVIDENCE-CONTRACT.md), [30](../30-CRAWL-RENDER-CONTRACT.md), [33](../33-EVENT-JOB-CONTRACT.md) and [34](../34-SECURITY-TENANCY-DATA.md) require scoped provenance, current authority, atomic acceptance and privacy filtering before retention.

For the local synthetic profile, accept only strictly conforming worker output whose original stdout digest and operational envelope match the independently stored terminal witness and exact render job/reservation/source descriptor. Browser build is trusted host configuration associated with the bound image, not a queue or model argument. Recheck live lease/release/tool permission, scope, deletion and source/audit eligibility after all external artifact work. Accounting settlement after cancellation never grants acceptance authority.

Before uploading anything, create a versioned privacy-limited projection. Inert parsing removes form/control/editable regions and unsafe embedded payloads; a conservative semantic element/attribute allowlist excludes event/data/style channels. Relative or query/fragment-bearing URL attributes are withheld entirely, so removing a base declaration or query cannot invent a different observed destination. Suspicious URL-bearing text is withheld. The already admitted source URI is separately minimized by withholding its query/fragment; that redacted URI is not a new navigation identity. Denied resource URLs are entirely withheld; nonstandard method names become OTHER. These transformations are deliberately lossy. They are not a claim of arbitrary secret detection or permission to process customer data.

Unredacted stdout and original DOM remain transient. Retained DOM projections have distinct Evidence IDs and byte hashes, explicit `render-privacy-v1` and `privacy_limited` coverage. Original hashes are non-retained provenance only; no reconstruction claim. The retained manifest is a separate versioned contract. Every locator addresses retained bytes. Removed content cannot support absence, structured-data coverage, link-count, or raw/render parity conclusions. This prerequisite does not release a parity Skill.

Bound input/output sizes, parser nodes/depth, V8 heap and wall time; terminate parser workers before returning. This is trusted inert parsing with resource bounds, not an OS security boundary or authorization to execute page JavaScript. Uncertain parse/encoding/budget outcomes reject retention without raw fallback. Existing raw HTTP fixture retention is separate and is not certified by this change.

A separate `aios_render_acceptor` collection-service identity owns the narrow acceptance function. Scheduler, renderer and supervisor credentials cannot call it, and the acceptor does not inherit scheduling/dispatch/mutation powers. The trusted collection adapter verifies/transforms private bytes; SQL authenticates stored invocation/terminal context and bounded transformed metadata, not arbitrary blob content. Browser output never possesses these credentials.

Upload bounded transformed artifacts before the tenant knowledge-clock lock, under the shared artifact-maintenance fence through acceptance. Revalidate current authority and authenticate the stored supervisor transcript in the acceptance transaction. Atomically insert Evidence, a partial or failed Observation, immutable invocation-to-artifact mapping and outbox event. Exact replay returns the original identities; changed transcript conflicts. Concurrent losing uploads are private unreferenced objects, never Evidence. Cleanup uses the existing artifact maintenance boundary.

This step does not project RenderSnapshot/ResourceObservation or complete the render job. Those require a subsequent typed projection transaction and canonical completion event; generic completion remains forbidden. Nonconforming worker output retains operational accounting only, not fabricated collection evidence. No customer activation, external resource access or website-write capability is enabled.
