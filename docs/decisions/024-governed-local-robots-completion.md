# ADR-024: governed local robots projection and fetch completion

Status: Accepted reversible local engineering default.
Date: 2026-09-19.

[ADR-023](023-governed-local-http-evidence.md) retains scoped observed response evidence. Add the missing narrow operational robots result and atomic fetch completion under [26](../26-TEMPORAL-EVIDENCE-CONTRACT.md), [30](../30-CRAWL-RENDER-CONTRACT.md), [33](../33-EVENT-JOB-CONTRACT.md) and [35](../35-QUALITY-SELF-AUDIT-GATES.md). No new canonical Robots domain entity is needed: accepted Evidence and Observation remain the factual record.

The projection takes only the original governed fetch lease and derives its accepted invocation/receipt/body from immutable acceptance records. No arbitrary caller-selected observation can substitute. Revalidate exact retained canonical receipt and body hashes, reviewed fixture retention, source scope, parser/policy context and observation freshness. Recheck current release, audit and deletion restrictions before and after artifact reads; no network or artifact read holds the work/knowledge clock lock.

Use the existing tested robotsState classifier without inventing page eligibility. The local result pins parserVersion=robots-v1 to the existing internal robots parser/status semantics and policyVersion=discovery-v1; future semantic changes require a version change. The result contains status/reason and accepted IDs, not executable Allow rules. Preserve known/parsed, known/not_available, denied/access_denied and unknown reasons. A valid unknown or denied result may complete this bounded observation job; it does not authorize new page requests or complete the crawl. Status404/410 means rules unavailable,401/403 means access denied; transport failure and incomplete ordinary responses remain unknown. For ordinary successful responses only text/plain without a collection error is eligible for robots parsing; other retained MIME types are withheld from the classifier and yield unknown/unavailable_or_incomplete. This conservative adapter check prevents HTML containing a colon from becoming an empty Allow policy. Shared robotsState status precedence is unchanged. No SEO finding or sitewide coverage is inferred from the result.

Persist an immutable operational projection receipt pinned to original job/invocation, accepted evidence/observation, parser/policy and freshness. Atomically commit that result, complete the fetch child with the accepted Observation as result_ref, clear its lease, and emit exactly one job.completed event at the Observation's next aggregate version. Do not create a PageSnapshot for robots.txt, duplicate evidence.recorded or refund consumed capacity. Generic completion remains forbidden outside the narrow projection function.

Completed replay proves the original attempt/token through the immutable reservation and accepted invocation, checks current authority and source freshness again, and returns the same result without new event or knowledge sequence. Changed context, wrong attempt or newly restricted input fails closed. No automatic next dispatch, recurring worker, public/customer processing or website-write capability is installed.

The trusted scheduler adapter performs exact retained-byte validation, reviewed retention, parsing, full audit-graph and external deletion-ledger checks. SQL authenticates accepted associations/bytes and constrains status outcomes and atomic completion; it does not duplicate the JavaScript robots parser or independently read the deletion file. No worker/client receives scheduler credentials.
