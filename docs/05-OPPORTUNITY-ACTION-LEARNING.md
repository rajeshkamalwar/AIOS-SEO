# Opportunity, Action and Learning

## Search Territory
- **Owned:** valuable visibility already held.
- **Contested:** close competition.
- **Opportunity:** realistically winnable next.
- **Expansion:** viable after authority/context improves.
- **Unviable now:** poor expected return at current maturity.

## Opportunity dimensions
Demand, relevance, intent, geographic fit, business value, current position, feasibility, expected impact, confidence, competition, cost, time-to-signal and risk.

## Universal action lifecycle
`Detect → Investigate → Evidence → Hypothesis → Prioritize → Propose → Risk check → Preview → Approve/Auto → Execute → Verify → Monitor → Measure → Learn`

## Experiment loop
`Hypothesis → Baseline → Controlled change → Deploy → Observation window → Frozen evaluation → Keep / Iterate / Revert → Learn`

Risk modes: **Auto / Review / Expert Review / Block**.

Never infer strong causality from ranking movement alone; search is noisy and external conditions must be considered.
