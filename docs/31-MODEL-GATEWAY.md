# 31 — Model Gateway

Status: provider-independent request/result contracts in spec/model-request.schema.json, spec/model-result.schema.json and spec/inference-output.schema.json.

Tasks: business_inference, page_classification, entity_extraction and opportunity_explanation. Routing uses capability requirements, supported language, independently evaluated task quality, approved data region/use policy and remaining budget. “High” reasoning tier permits a capable reasoning model without naming any vendor in domain records. A provider adapter maps local requirements to its API; unsupported features yield model_unavailable.

Input is an immutable tenant/site EvidenceBundle plus redacted content segments and locators. Untrusted content is data, separated from system policy. Prompt digest and skill digest pin behavior; exact rendered request/config and output are retained only under data policy. No chain-of-thought storage requirement. Models receive no tools, credentials, direct network, other-tenant retrieval or authority fields to modify. Their citations are candidate references, not accepted provenance.

Before call, reserve input+maximum output tokens and currency at current versioned price ceiling. A run permits8 total calls/40000 total tokens/$2 configured cap; per call≤12000 input/2000 output,90s and at most2 attempts. Retries/repairs/fallbacks count against all run budgets. Unknown price or data policy blocks external calls. Timeout retains reservation until usage reconciles; worst-case cost is charged if outcome cannot be established. No double nested retry multiplying call limits.

Validate JSON with local schemas, no coercion, then reference membership, locator integrity, temporal cutoff, evidence entailment and capability-specific rules. Schema success cannot prove a business claim. Literal observed extraction requires exact source support; inferred claims retain provisional status and cannot assert service radius, qualifications or performance. Contradiction is retained. Invalid output has output=null in the accepted result and a classified validation error; raw failed output remains quarantined under retention. A validated result requires non-null output/hash and empty validation_errors.

One bounded repair or approved equivalent fallback is allowed within max_attempts=2. Equivalence includes privacy and task evaluation, not just JSON compatibility. Failure falls back to deterministic extraction of literal page declarations or abstention; no fabricated Twin. Opportunity ordering/quotas are deterministic; explanation text cannot add claims. Model replacement requires frozen35 quality tests before customer use. Fixture adapters are explicit synthetic test infrastructure and must not appear as real model understanding.
