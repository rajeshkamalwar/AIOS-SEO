# Complete Search / SEO Universe

The Brain must eventually cover:

1. Business context and archetype
2. Customer, problem and search intent
3. Demand, keywords, topics and entities
4. Crawl discovery and crawl paths
5. Indexability and index coverage
6. HTTP status, redirects and migrations
7. URL normalization and canonicalization
8. robots.txt, meta robots and snippet controls
9. XML sitemaps and freshness
10. JavaScript/rendering/hydration
11. Site architecture, taxonomy, navigation and breadcrumbs
12. On-page relevance, titles, headings and snippets
13. Content usefulness, originality, completeness, freshness and decay
14. Internal linking, anchors, orphans and authority flow
15. Structured data and machine readability
16. Image and video search
17. Core Web Vitals, performance and mobile
18. Local SEO, Maps/business identity, reviews and citations
19. Ecommerce categories/products/variants/facets
20. International/multilingual/hreflang
21. Backlinks, mentions, authority and reclamation
22. Brand/entity/reputation
23. SERP features, volatility and intent shifts
24. Competitor intelligence
25. Google Search Console and Google search surfaces
26. Analytics and conversion attribution
27. Bing Webmaster and IndexNow
28. AI Search / AEO / GEO visibility
29. Search policy, spam and security integrity
30. Experiments, monitoring, protection and regression
31. Reporting and business-language interpretation
32. Brain reliability, skill freshness and self-audit

Every family expands into: **Observe → Evidence → Diagnose → Skill → Decide → Action → Risk → Validate → Measure → Learn.**
